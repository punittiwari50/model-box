# @model-box/model-connector-ui

Modern responsive React Web and Mobile UI for the ModelConnector Platform.

## Features

- **Omni-Channel Model Chat**: Live multi-model conversation interface with real-time token metrics and latency telemetry.
- **Visual Strategy Toggle**: Switch on-the-fly between **CLI Strategy**, **REST API**, and **Cookie Session** modes.
- **Model Registry & Capabilities**: Visual card grid of discovered models from upstream Gemini Model Connector and local runtimes.
- **Session Lineage & Cookie Vault**: Cookie jar inspector and multi-turn state manager.
- **Upstream Gemini Connector Sync**: Live health monitor and immutable compliance audit trail viewer.
- **Dual Form Factor**: Responsive layout optimized for desktop widescreen and mobile devices (touch-friendly bottom navigation).

## Development

```bash
npm run dev
```
Runs at `http://localhost:3005`.
